# Vehicle Fuel Efficiency Visualizations

This folder contains visualizations generated during Exploratory Data Analysis (EDA) for the project **AI-Based Vehicle Fuel Efficiency Anomaly Detection**.

## Visualizations

1. **Distribution Analysis** — Shows the distribution of combined fuel efficiency (MPG) using a histogram.
2. **Trend Analysis** — Shows the relationship between engine displacement and combined fuel efficiency using a scatter plot.
3. **Category Analysis** — Compares average fuel efficiency across different fuel types using a bar chart.
4. **Correlation Analysis** — Displays correlations between numerical vehicle variables using a heatmap.

## Tools Used

- Python
- Pandas
- Matplotlib
- Seaborn

These visualizations help explore vehicle characteristics and identify patterns that may require further investigation.
